# Forecasting Electricity Grid System Imbalance — Python

## Problem Statement

Develop a time-series forecasting model to predict the sign of electricity grid system imbalance one and two 15-minute time steps ahead.

## Objectives

- Prepare and explore historical time-series data.
- Visualize temporal patterns and analyze autocorrelation.
- Compare statistical forecasting models and select suitable parameters.
- Evaluate out-of-sample sign prediction accuracy.
- Interpret the results and identify potential model improvements.
