## Problem Statement

Develop a probability-of-default (PD) scorecard for home-equity loan
applicants using historical loan and borrower characteristics.

## Objectives

- Assess the explanatory power of candidate variables
- Select variables for the final scorecard
- Analyze and transform categorical and continuous variables
- Develop meaningful risk bands using binning and WoE/IV analysis
- Build and evaluate a logistic regression-based PD model
- Assess out-of-sample predictive performance
