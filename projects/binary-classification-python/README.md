# Binary Classification — Recipe Site Traffic

## Problem Statement

Develop a binary classification model to predict whether a recipe will generate high website traffic when featured on a homepage, targeting at least 80% recall while maximizing precision.

## Objectives

- Validate and preprocess the dataset.
- Explore recipe characteristics and their relationship with website traffic.
- Develop and compare logistic regression and XGBoost models.
- Optimize the classification threshold to achieve the target recall while maximizing precision.
- Evaluate model performance and provide business recommendations.
